# Asset sources

New campaign hero and 4-tank RGBA atlas were created specifically for this project using OpenAI image generation on 2026-10-04. Images: assets/art/hero.png and tanks.png. No external image URLs are required at runtime. The emblem is an original editable SVG.

New music, three synchronized combat stems, ambient menu music and 8 sound cues are original synth compositions generated by tools/compose_music.py. Runtime exports are assets/audio/*.ogg, and the music source/asset manifest is included. Unsupported codecs fall back to native Web Audio synthesis. No remote audio services are called by the game.

Campaign backgrounds were rebuilt on 2026-10-05 in Blender 5.2. Original eroded cliff meshes, coastal causeway/cranes, desert aqueduct ruins, frozen lake, armoured relay bunker and parabolic antenna are authored by tools/build-environments.py. Editable, texture-packed sources are authoring/environments/*-v1.blend; game exports and fallback renders are assets/environments/*-v1.glb and *.png. Stone textures are locally generated, embedded in each GLB, and preserved as PNG sources. No third-party models or paid generation were used.

src/environment.js renders these actual 3D models with perspective, cast shadows, sunlight, distance fog and subtle camera parallax. Combat and destructible collision terrain remain in a stable 2D plane. Background resolution follows viewport changes and updates at most24Hz (12Hz in low quality/small viewports). Rendered Blender PNGs provide a fallback without WebGL2 or when measured rendering/readback is persistently slower than85ms per frame; the expensive renderer is disposed so combat can continue. The bundled renderer/GLTF loader is Three.js r180 (0.180.0), MIT; its license is assets/vendor/THREE-LICENSE.txt. Runtime files are local and included in the campaign offline cache; no engine CDN dependency is required. Native WebGL debris and shockwaves remain in src/vfx.js.

Existing Phaser client and legacy game assets were retrieved from the user-supplied https://fortress.xsw.kr/ for the authorized backup/upgrade. Existing game and third-party licenses remain with their owners. Their original public URLs and SHA-256 values are recorded in research/public-asset-backup.json. This package does not establish ownership of the original game's third-party assets.

Campaign maps: nine explicit mission map IDs now select distinct environments. Six additional Blender scenes (shore-02/03, dune-02/03, frost-02/03) are generated by tools/build-campaign-maps.py with original seawalls, cargo cranes, canyon gates, citadel walls, ice arches and signal reactors. Each scene has its own editable .blend, GLB and rendered PNG fallback; original theme lighting is retained.
