# Asset sources

New campaign hero and 4-tank RGBA atlas were created specifically for this project using OpenAI image generation on 2026-10-04. Images: assets/art/hero.png and tanks.png. No external image URLs are required at runtime. The emblem is an original editable SVG.

New music, three synchronized combat stems, ambient menu music and 8 sound cues are original synth compositions generated by tools/compose_music.py. Runtime exports are assets/audio/*.ogg, and the music source/asset manifest is included. Unsupported codecs fall back to native Web Audio synthesis. No remote audio services are called by the game.

New battle backgrounds, terrain, HUD markers, projectile feedback and weather are procedural Canvas drawings in src/battle.js. True 3D debris, point sprites and shockwave geometry use local native WebGL shaders in src/vfx.js, with a Canvas fallback. There is no additional engine CDN dependency.

Existing Phaser client and legacy game assets were retrieved from the user-supplied https://fortress.xsw.kr/ for the authorized backup/upgrade. Existing game and third-party licenses remain with their owners. Their original public URLs and SHA-256 values are recorded in research/public-asset-backup.json. This package does not establish ownership of the original game's third-party assets.
