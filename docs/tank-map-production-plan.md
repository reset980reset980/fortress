# Fortress Afterlight 전차·맵 제작 계획

작성: 2026-10-05. 사용자의 전체 적용 승인 후 이 계획의 캠페인·AI 콘텐츠를 구현했다. 구현·검증 범위와 온라인 미검증 사항은 expansion-release.md에 기록했다. 아래는 승인 당시의 제작 계획이다.

## 조사에서 얻은 설계 방향

- Fortress 2 BLUE 개발팀은 바람·각도 기반 포물선 사격, 파괴 가능한 지형, 전차별 고유 탄환 물리를 핵심으로 설명한다. 출처: https://steamcommunity.com/app/3152590/allnews/?l=french
- Fortress V2 개발팀의 밸런스 공지는 다연장 로켓, 독가스탄, 수리, 위성탄, 태양 에너지 등 서로 다른 무기와 능력을 별도로 조정한다. 외형과 체력만으로 전차를 구별하지 않는 설계를 참고한다. 출처: https://steamcommunity.com/app/1279580/allnews/
- Fortress S 공식 소개는 29종 전차 수집과 클래식 턴제 모드를 소개한다. 수집은 물량보다 선택하고 익히고 성장시키는 흐름으로 설계한다. 출처: https://www.nintendo.com/us/store/products/fotress-s-switch/

아래 이름·수치·제작 순서·맵 아이디어는 위 자료를 바탕으로 한 Afterlight의 신규 설계 제안이다. 원작 이미지나 전차 외형을 그대로 사용하는 계획이 아니다. 원작 전체 맵·전차를 직접 플레이하거나 내부 수치를 역분석한 상태는 아니다.

## 현재 게임과 우선 개선점

소스 기준 전차 4종, 캠페인 9작전, 선택 가능한 맵 12개, 공용 무기 3종, 개량 6종이 있다. 다층 지형·파괴·낙하와 포물선 사격, AI, 오프라인 실행을 재사용할 수 있다.

1. 전차는 주로 체력·공격 배율·기동력 차이이며 고폭탄·집속탄·플라즈마를 공유한다. 전차마다 기본탄·특수탄·고유 능력을 만들어 실제 플레이를 구분한다.
2. 같은 테마의 배경과 시드 차이에 의존하는 맵을 줄인다. 새 맵은 높이, 통로, 엄폐, 지반 강도, 낙하 후 동선 중 최소 두 가지가 다르게 작동해야 한다.
3. 외형 단계는 최고 개량 레벨 하나로 선택된다. 후속 성장 설계에서는 부품 성장과 차체 진화를 구분하고, 한 항목만 올려 최종 차체가 되는 규칙을 개편한다. 기존 개량 성능·포인트·기체 선택은 마이그레이션으로 유지한다.

목표: 기존 전차 4종을 재설계하고 신규 8종을 더해 총 12종. 신규 맵 12개를 추가해 선택 맵 총 24개. 기존 캠페인 9작전은 유지하며 신규 9작전으로 18작전까지 확장한다. 동일 맵을 캠페인과 자유대전에 재사용한다.

## 강화 모델과 자산 제작 계약

전차마다 기본형+강화 5단계, 총 72개 차체 모델이 목표다. 신규 8종에 필요한 차체는 48개이며 기존 24개도 이 규격으로 점검한다.

- 전차별 기획표에 단계별 포탑 모양, 장갑 배치, 포신 방식, 엔진·장치 위치를 먼저 정의한다.
- 단계별 동일 카메라·바퀴 간격·화면상의 폭·접지 기준을 고정한다. 강화될수록 크기를 키우거나 색만 바꾼 이미지는 채택하지 않는다.
- 기본형·중간형·최종형을 먼저 비교하고 통과한 디자인 사이에 나머지 단계를 설계한다.
- 포신과 차체는 가능한 한 별도 레이어로 제작한다. 포구·포탑 회전축·궤도 접지점·피격 중심 좌표를 manifest에 기록한다. 포신 각도와 발사 반동이 실제 스프라이트에 일치하게 한다.
- 궤도/바퀴 이동 애니메이션, 정지·발사·피격·파괴 상태를 준비한다. 기본 모델의 상태 연출을 공통 레이어로 사용하고 모든 강화 단계에 중복 이미지 수백 장을 만들지 않는다.
- 각 전차에 선택 썸네일·기체 설명·탄환 2종·발사/비행/명중 FX·발사음/구동음을 묶는다. 비슷한 섬광을 색만 바꾸는 방식은 줄인다.
- 맵은 먼저 충돌 구조를 제작하고 실제 사격·파괴·낙하를 검증한다. 그 뒤 Blender 배경·전경·조명·썸네일을 같은 구조에 맞춰 제작한다.
- 모바일용 배경·이펙트 품질, 오프라인 자산과 캐시 업데이트를 함께 준비한다.

격납고에는 현재 모델, 다음 강화 모델, 변화하는 부품을 크게 보여준다. 구매 전에 강화되는 능력과 실제 외형을 함께 비교한다. 기체 해금과 부품 개량은 포인트와 캠페인 진행으로 가능하게 하고, 기존 아이템과 기록은 유지한다. PvP를 새 클라이언트로 연결할 때는 경쟁용 표준 능력치와 성장형 자유대전을 분리하는 것을 제안한다.

## 실제 제작 순서와 완료 기준

### 1차: 정체성 확보 — 총 전차 6종, 총 맵 15개

기존 4종에 고유 무기를 부여하고 모타르·몰, 공중 정원·붕괴 교량·폐광 협곡을 추가한다. 먼저 모타르 1종과 붕괴 교량 1맵을 완성해 전체 품질 기준을 세운다. 차체 6단계·포신 회전·기체 구동·무기 2종·낙하 지속·썸네일·저장·오프라인까지 한 묶음으로 완성한다.

통과 기준: 같은 포인트 조건에서 역할이 구별됨, 지형 파괴탄과 공격탄의 선택 이유가 있음, 배경과 충돌면이 일치함, 좌우를 바꿔도 동일한 사격 해법이 나옴, 강화 스프라이트가 같은 크기에서 구별됨, 모바일에서 전차와 포탄이 읽힘.

### 2차: 무기 다양성 — 총 전차 9종, 총 맵 18개

하이브·베놈·글레이셔와 네온 도크·수정 동굴·빙하 균열을 추가한다. 다연장 분산·지속 피해·냉각 효과·필요한 반사 지형을 구현한다. AI의 피해 예측에 잔여 독 피해·지형 붕괴·효과 지속 시간을 반영한다. 새로운 전선 3작전을 먼저 연결한다.

통과 기준: 상태 효과가 중첩으로 무한 지속되지 않음, 특수탄 자원·턴 처리가 정상, 동일 고각/고화력 전략 하나가 모든 전차를 지배하지 않음.

### 3차: 숙련·수집 확장 — 총 전차 12종, 총 맵 24개

볼트·리코셰·솔라와 나머지 6개 맵을 추가한다. 기존 9작전+신규 9작전으로 캠페인을 확대한다. 전차별 숙련 보상과 승리 포인트, 모델·부품 비교와 컬렉션 화면을 완성한다. 낮은 중력과 반사탄은 별도 회귀 테스트 후 적용한다.

완료 기준: 모든 전차가 캠페인·자유대전·AI·모바일에서 동작, 새 맵을 선택하면 실제 해당 구조가 나옴, 기존 저장 마이그레이션 정상, 모든 필수 자산 오프라인 캐시, 서버 백업·복원 확인 후 정적 루트 배포.

## 밸런스와 검증 계획

- 사격 수치: 기본탄 피해, 직격 보너스, 폭발 반경, 지형 반경, 탄속, 중력 배율, 바람 민감도, 탄약, 재사용 대기시간을 독립 정의한다.
- 초기 통제 실험: 전차 조합별·맵별 고정 AI 설정으로 시작 위치와 선공을 교환해 각각 반복 대전한다. 초기 예시 목표는 전체 승률 45~55%이며, 상성별 결과와 AI 숙련 편향을 함께 기록한다. AI 결과만으로 사람 PvP 균형을 확정하지 않는다.
- 지형: 시작 지지면·이동 가능 거리·탄도 해법·지반 파괴량·층간 낙하·아래층에서 위층으로 발사·대칭 판정 검사.
- 타격감: 전차 종류·무기별 발사 반동, 피격 방향, 지면 충격, 저품질·동작 줄이기, 정지·음소거·탭 숨김·재시작 시 오디오와 FX 정리.
- 실제 브라우저: 모바일 세로/가로와 PC에서 선택→강화→사격→승리→보상→새로고침 후 저장 유지까지 검증한다.
- 운영 적용은 실제 정적 루트 바깥에서 제작·검증하고, 전체 정적 백업과 복원 검증 후 기존 배포 스크립트를 사용한다. API/DB/프록시와 기존 온라인 게임은 유지한다. 온라인 신형 콘텐츠는 실제 서버 프로토콜 연결을 구현·검증한 뒤 별도 완료 처리한다.

일정은 확정하지 않았다. 1차 완성 샘플의 제작 시간과 모바일 성능을 측정한 뒤 후속 자산 생산량과 개발 일정을 산정한다.
